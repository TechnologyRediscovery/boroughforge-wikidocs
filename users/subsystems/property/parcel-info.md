# Parcel Info

**Property info:** The most direct way to designate properties as rentals, multi-units, etc.
is through the Property Info box.

1. Navigate to your desired property page.
2. In the left column, find **Property Summary** and click **edit property info**.
3. This brings up a dialog where you can configure a lot:
   - Use the **Use Type** dropdown on the left to select the desired use type.
   - On the right, you can also flag a property for Unfitness of Occupancy, Vacancy, and
     [Abandonment](#mark-a-property-as-abandoned).
     - When flagging any of these three conditions, you enter start and stop dates so there's
       a record of when the condition began and ended.
4. Save the changes — the new info appears on the property profile page.

## Mark a property as abandoned

Abandonment is one of the three condition flags set from the **edit property info** dialog
described above (alongside Unfitness of Occupancy and Vacancy). Set a start date when the
property is flagged abandoned, and a stop date once the condition ends.
