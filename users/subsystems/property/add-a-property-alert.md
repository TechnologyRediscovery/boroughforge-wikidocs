# Add a Property Alert

1. Start on a property landing page.
2. Scroll down to the events box and click **Add Event**.
3. Click **Property alerts**.
4. Select the alert you would like to add to the property.
5. Click to add a description.
6. Click the date field...
7. ...to choose the date when you are setting the alert.
8. Click **Create new event**.
9. Click the property address to refresh the page.
10. The alert now appears on the property landing page.

    > **Tip:** Adding these alerts can help let other officers know about potentially
    > dangerous conditions.

See [Setting up property alert events](/users/subsystems/property/property-alerts-setup) for
how the underlying alert event categories are configured.
