# Session Property

1. The property tab shows the "Session Property". In some municipalities, this is the address
   of the borough building by default.
2. Clicking the address brings you to that address's property page.
3. To change the session property, search for a different address (see
   [Property search](/users/subsystems/property/property-search)).
4. After searching for a new property, the information in the property box changes, along
   with the information in the...
5. ...person box.

   > **Tip:** This may not always show the owner — it could be someone else associated with
   > the property. Click the property and scroll to the bottom left to see all the people
   > associated with the property and their roles.
6. ...and the CE (Code Enforcement) case box also changes.
7. Click **view permit file**...
8. ...to load a permit file associated with the property.
9. Click **cases on sess prop**...
10. ...to see the "Open case list".
