# Property Unit Configuration

1. Start on the property landing page.
2. To the right of the screen, you'll see the "Units, Permit Files, and Inspections" box. Here
   you can see each unit associated with a property and its attached permit files.
3. Clicking **view/edit unit**...
4. ...lets you see the unit information, permit files, mailing addresses, and person links.
5. To add a new unit, click **Add new unit**.
6. For a single family home, "Primary" as the unit name is fine.
7. Or, you can add unit numbers or names. This works for unit numbers in an apartment
   building.
8. It could also be another name, like "Basement", if there's another rental unit on the
   property.

   > **Tip:** The unit name/number is visible on the printable permit file.
9. Here you can add mailing addresses for separate units.
10. Clicking **Persons** lets you add tenants to the units.

    > **Tip:** Each unit has a permit file/inspection attached to it — even a single family
    > home counts as a unit. This function helps ensure that individual rental units have
    > separate permit files.
