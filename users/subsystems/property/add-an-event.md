# Add an Event to a Property

1. Start on the property landing page.
2. Scroll down to the "Events attached to parcels" box.
3. Click **Add Event**.
4. Choose the event type that best suits the event you're recording. This is a general type —
   you'll choose a more specific event category in the next few steps.
5. This example uses "communication". Selecting an event type filters the event categories,
   making the next step quicker.
6. Navigate to **Pick an event category**.
7. Because "Communication" was chosen as the event type, the categories shown are all
   communication categories. This example uses "phone call".
8. Review or change the **category details**.
9. Click to enter a description of the communication.
10. After entering a description of the event (what was discussed in the phone call/in-person
    conversation, etc.), click **Create new event**.

    > **Tip:** Adding these to a property can help you recall details about a property or
    > property owner if ever asked about them in the future — for example, in preparation for
    > court or for internal review purposes.
