# Code Enforcement Cases — User Guide

CodeNforce supports the following general case management flow:

1. Open a case from a street patrol, a failed inspection, an action request from muni staff,
   or a request from the public.
2. Conduct a field inspection.
3. Identify violated ordinances.
4. Log events.
5. Send a notice or a letter.
6. Create and track citations.
7. Store photos and documents.

## Caseload manager

The dashboard features a caseload manager which categorizes your municipality's open cases
into priority bins and offers a suite of quick actions directly from each case card: closing,
letter viewing, finalizing, marking as sent, and event logging.

Batch case operations can be initiated directly from the caseload manager. As of March 2026,
only case closure is an available batch action.
