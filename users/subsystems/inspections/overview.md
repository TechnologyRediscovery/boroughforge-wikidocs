# Inspections — User Guide

Inspection objects span both the `occupancy` and `cecase` subsystems — inspections are not
exclusive to either, so this branch covers the tools common to both.

- [Managing inspected spaces](spacetools) — space list, space details dialog (location, size,
  occupancy restrictions, notes), and setting a custom space display order.

See the [hub page](/system/subsystems/inspections) for links to the other branches, and the [subsystem registry](/system/subsystem-registry) entry #9 for scope notes.
