# Create a Permit File

Creating a new permit file, with optional steps to generate a report, certificate, or
reinspection.

## Create the permit file

1. Navigate to the dashboard.
2. Search for the property.
3. On the property page, click **Add new permit file**.
4. Click **Choose a unit on this property** (if there isn't a unit, choose PRIMARY) or add a
   new one.
5. Click **select a permit file type**. Types are set up during onboarding — usually rental or
   property transfer. The permit file type holds the certificate types.
6. Add the origination category (also set up with admin), such as "application received" —
   what action prompted the permit. This is recorded as an event.
7. Click **Create new permit file and go to profile**.
8. The permit file holds the inspection, certificate, events, etc. The origination event is
   viewable under Events.

## Start an inspection

9. Click **New inspection** to start an inspection.
10. Click **Edit checklist** — checklists can be set up with the admin (see checklist
    instructions).
11. Click the checklist you are using.
12. Click **Update inspection to use selected checklist**.
13. Enter any inspection-related data. Click **Dispatch to mobile** if sending to the app.
14. Click **Create new inspection**.
15. Click **Start inspection!**

## Inspect spaces

16. Select the spaces set up on the checklist.
17. Click **Inspect selected space**.
18. Click **Table view & batch actions** (tree view is not currently recommended).
19. Enter the status of the violation.
20. Click **Choose a batch status** if batching all — use batch status first, then change any
    individual items as needed.
21. Add a finding in the text box; canned findings can be set up and stored.
22. Click **Save and continue to photos**.
23. Click **Done! Back to inspection profile**.

## Attach photos

24. Click **Add Photos**.
25. Click **Choose**.
26. Click **Upload**.
27. Select the uploaded photo.
28. Click **Inspect! (edit ordinances, pass/viol, photos and findings, remove space)**.
29. Click **Photos and findings**.
30. Click **Add/remove photos**.
31. Click **Attach to checklist item**.
32. Click **Done! Return to space summary**.
33. Click **Done! Back to inspection profile**.

## Finalize the inspection

34. Click **Finalize inspection**.
35. Click **Choose a determination**.
36. Click **Violations identified (Fail)** (or the appropriate determination).
37. Click **Finalize inspection ID [n]**.
38. If you would like a follow-up event on the calendar, add the number of days, then click
    **Finalize and lock**.

## Optional follow-ups

> **Note:** A certificate can be created after the inspection is complete.

39. Click **Create new certificate w/steps**.

> **Note:** An inspection report can also be created.

40. Click **Build Inspection report**.
41. Click **Generate Inspection Report in new tab** — the report opens in a new tab; use
    <kbd>Ctrl</kbd>+<kbd>P</kbd> to print.

> **Note:** A reinspection can be created after an inspection.

42. Click **Reinspect**.
43. Click to dispatch.
44. Click **Generate follow-up inspection**.
45. Confirm "Dispatched to mobile application" — the reinspection has been dispatched.
