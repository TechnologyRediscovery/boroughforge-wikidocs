# Permitting — User Guide

All permitting occurs in objects called **permit files**. A permit file is a container for
inspections, events, certificates, and documents & images.

## Permit file pages

- [Creating a permit file](/users/subsystems/permitting/creating-permit-files)
- [Configuring canned comments on certificates](/users/subsystems/permitting/managing-canned-cert-text)
- [Linking permit files to code enforcement cases](/users/subsystems/permitting/linking-permit-files-to-ce-cases)

## About permit files

Permit files always live inside a property unit. By default, properties are created with a
unit called PRIMARY. Single family homes likely do not need any additional unit configuration,
and permit files can be created directly inside the PRIMARY unit.

Multi-unit parcels should have their unit list configured to reflect the divisions actually
present on the parcel. The PRIMARY unit should either be deactivated or changed to represent
the common areas or exterior of the property. See
[Property unit configuration](/users/subsystems/property/unit-configuration).
