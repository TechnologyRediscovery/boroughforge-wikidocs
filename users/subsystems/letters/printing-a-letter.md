# Printing a Letter

When a letter is finalized, CodeNforce automatically generates a PDF of the frozen letter
content — including any photos, laid out using the template's configured print format and
orientation (portrait for a standard letter, landscape for placards and door-hanger
notices). Recipient photos and signature images are baked into the PDF directly, so it prints
exactly as previewed on-screen.

General browser/printer setup (Google Chrome, print dialog options, etc.) is the same as any
other document in CodeNforce — see [Printing from CodeNforce](/users/basics/printing) for
that general guidance.

See also: [Generating and sending a letter](/users/subsystems/letters/generating-and-sending-a-letter),
[Distributing a letter](/users/subsystems/letters/distributing-a-letter).
