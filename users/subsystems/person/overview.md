# Person — User Guide

"Persons" in CodeNforce are any and all people or businesses associated with a property within
a municipality. Individuals like homeowners, tenants, or property managers are entered into
the system the same way as businesses. Using person search will bring up both individuals and
businesses that match — for example, searching "Jones" could return both Frank Jones (a
homeowner) and Jones Realty (a property management group). These two entries may have nothing
to do with each other, but both could come up in the same search.

Person search is the only search in CodeNforce that crosses municipality lines, allowing
municipalities to share important data and leverage PA Act 90 if need be — letting
municipalities see if a person has a case open or citations filed against them in another
municipality.

No matter the type of person, the person profile stores the same data points: mailing
address, phone number, email address, and their association to properties. Completing person
profiles as data comes in, and keeping roles updated, helps ensure that everyone in a
municipal office — and other municipalities using the system — shares accurate data. Most
workflows in CodeNforce will prompt you to link a person to the action, whether it's a permit
file, code enforcement case, or citation.

> **Important:** Before adding a new person, always search for an existing record first. This
> prevents duplicate people from being added to the system and keeps data sharing working as
> intended.
