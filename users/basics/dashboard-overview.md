# Dashboard Overview

1. Once logged into CodeNforce, you will see the dashboard landing page.
2. Along the top of the screen is where you navigate through the database.

   > **Tip:** Selecting the "dashboard" link at any time will bring you back to this page.
3. Scrolling down, you will see the Event Calendar.
4. Past the calendar is where you can run various queries in the database.
