# Printing

> **Tip:** You can print several different types of letters or permits — the overall process
> is very similar across all printable documents. This walkthrough uses a Notice of Violation
> (NOV) as the example.

1. Start on a code enforcement case landing page.
2. Find the letter types and templates panel.
3. This example uses a lightening case, which already has an NOV drafted. For a regular case,
   select **New Letter**, then generate an NOV for the violations.
4. Click **Preview draft** to look at the text of the letter before finalizing.
5. Review the sample text.
6. Click **Edit letter text** to make any changes.
7. Click **Choose addressee**.
8. Click **Select person**.
9. Select **Mail NOV to this address** under "Address links".
10. Click **Done! Return to NOV setup**.
11. Click **select a notifying officer user**.
12. Select whoever is sending the letter.

    > **Tip:** The notifying officer must have a phone number and email on file for this to work!
13. Edit any text if needed.
14. Remove any violations that shouldn't be included.
15. Click **Update notice text** to save the draft.
16. Click **Finalize and lock**.

    > **Alert:** After you select "finalize and lock" you cannot change the letter text. If
    > you need to amend something, you will have to create a new draft.
17. Click **Record mailing**. This is added as an event on the case.
18. Enter a number of days until the system should remind you about the NOV.
19. Click **Mark as mailed!**

    > **Alert:** Only mark something as mailed if you plan to mail it out **that day**. The
    > mailing date can come up in court — the saved event helps you remember it, but accurate
    > testimony is what matters most.
20. Click **Print**.
21. Review the final copy.
22. Printing looks different depending on your browser. In Google Chrome, click the three
    vertical dots in the top-right corner, then **Print**. Make sure there are no headers or
    footers on the document — use **More settings** to reconfigure the layout before printing.
