# User-Municipality Authorization Periods (UMAPs)

A UMAP allows a user to access a specific municipality at a specific permission level, from a
start date to a stop date.

See [Creating a new user](/admin/subsystems/accounts/overview) for the full account-creation
workflow this fits into.
