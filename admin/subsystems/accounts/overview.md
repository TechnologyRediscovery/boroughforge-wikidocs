# User Accounts — Admin Guide

Covers creating a new CodeNforce user account and granting that person access to a
municipality.

## Creating a new user

1. **Add the person first.** Every user account is tied to a person record — search for the
   person before creating a new one, to avoid duplicates (see
   [Person search](/users/subsystems/person/person-search)).
2. **Make sure the person has an email address on file.** The account/login flow requires it.
3. **Create the UMAP.** A User-Municipality Authorization Period grants the person access to a
   specific municipality at a specific permission level, for a date range. See
   [UMAPs](/admin/subsystems/accounts/umaps) for what a UMAP controls.

See also: [subsystem hub](/system/subsystems/accounts).
