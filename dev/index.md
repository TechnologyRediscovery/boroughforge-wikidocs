# Developer guide home
A living dumping ground for development notes and server administration guides related to the CodeNforce municipal code enforcement database management system.

[The git repo hosted on gitlab receiving active commits](https://gitlab.com/echocharliedelta/codenforce), but does not yet include documentation friendly to other developers wishing to spin up their own instance.

Contact creator Eric Darsow via email at the 3 words echo, charlie, delta spelled out at proton mail dot com.
