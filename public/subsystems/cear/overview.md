# Code Enforcement Action Requests (CEAR) — Public Guide

See something that might be a code violation — an overgrown lot, an unsafe structure, illegal
dumping, a property issue of any kind? You can report it to your municipality's code
enforcement office online, without creating an account.

## Topics

- [Submitting a concern](/public/subsystems/cear/submitting-a-concern) — the step-by-step
  reporting flow, from picking your municipality through getting your confirmation number.
- [Checking your request status and unsubscribing](/public/subsystems/cear/checking-status-and-unsubscribing) —
  looking up an existing request with your confirmation code, and stopping update emails if you
  no longer want them.

## What happens after you submit

A code officer reviews every submitted request, usually within about a week. Depending on what
they find, it may be attached to a new or existing code enforcement case, or closed out if it
turns out not to be something code enforcement can act on (for example, if it's not a code
violation, or belongs to another department entirely).

## What you can expect by email

- A **confirmation email**, if you asked for one when you submitted.
- Optionally, **status-update emails** as your request moves forward — only if you opted in,
  and only for municipalities that have turned this feature on. Every one of these emails
  includes a working unsubscribe link, no login required.
- Your personal information is never shared publicly. If you'd rather not be identified to the
  property owner or anyone else involved, you can request to remain anonymous when you submit.
