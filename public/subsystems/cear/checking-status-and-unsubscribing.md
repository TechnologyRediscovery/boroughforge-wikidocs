# Checking your request status and unsubscribing

## Checking status with your confirmation code

Your municipality's site has a **"View/Edit Existing Concern"** page (sometimes linked as
"Check request status"). Enter the **Public Access Control Code (PACC)** — the confirmation
number you were given when you submitted your request — to pull it up.

<!-- SCREENSHOT NEEDED: The "View/Edit Existing Concern" page showing the PACC code input box. -->

Once you've entered a valid code, you'll see the current state of your request — whether it's
still awaiting review or has already been routed to a code enforcement case or closed out.

<!-- SCREENSHOT NEEDED: The request status view after a successful PACC lookup, showing the
concern details and its current status. -->

> Don't have your code anymore? If you requested an emailed confirmation copy when you
> submitted, check that email — your confirmation number is included there. Otherwise, contact
> your municipality's code enforcement office directly for help.

## Unsubscribing from status-update emails

If you opted in to status-update emails and want to stop, every one of those emails has an
**unsubscribe link** built in — no login or confirmation code required. Click it and you'll
land on a simple confirmation page:

- **"You have been unsubscribed"** — the link worked; you won't get any further update emails
  about that request.
- **"You are already unsubscribed"** — you'd already opted out previously; no action needed.
- **"This unsubscribe link is not valid"** — the link may be incomplete or broken. Use the link
  from your most recent update email, or contact your municipality's code enforcement office.

<!-- SCREENSHOT NEEDED: The unsubscribe confirmation page showing the "You have been
unsubscribed" message. -->

Unsubscribing only affects future update emails about that one request — it doesn't withdraw
or change the request itself, and it has no effect on a one-time confirmation email you may
have already received.
